# 网络通信模块设计说明

## 模块概述

**文件位置**：
- `src/network/udp_receive.cpp/h` - UDP数据接收
- `src/network/udp_send.cpp/h` - UDP命令发送
- `src/network/UART_receive.cpp/h` - 串口数据接收

**主要功能**：
- UDP数据包接收与解析（ADC数据转电压）
- UDP命令包发送（控制下位机）
- UART串口通信（数字信号测量）

### 类结构设计

#### 核心成员变量

| 变量名 | 类型 | 说明 |
|--------|------|------|

| `expectedDataCount` | `quint32` | 期望接收的数据点数 |

### 数据接收流程图

```
FPGA发送UDP数据包
        │
        │ 每包含512个10-bit ADC值
        ▼
QUdpSocket::readyRead() 信号
        │
        ▼
UdpReceiver::onDataReceived() 槽函数
        │
        ├─► readDatagram() 读取数据包
        │
        ├─► 解析10-bit ADC值（2字节高低位拼接）
        │   └─► for (i = 0; i < length-1; i += 2)
        │       {
        │           highByte = data[i];
        │           lowByte = data[i+1];
        │           adc10bit = (highByte << 8) | lowByte;
        │           adc10bit = adc10bit & 0x3FF; // 保留低10位
        │       }
        │
        ├─► ADC值转电压 (参考MATLAB代码)
        │   └─► voltage = (adc10bit / 1023.0) * 5.0; // 0-5V范围
        │
        ├─► 计算时间戳（基于采样率）
        │   └─► for each sample:
        │       {
        │           time_us = (sampleIndex / sampleRate) * 1e6; // 微秒
        │           sampleIndex++;
        │       }
        │
        ├─► 检查是否达到期望数据点数
        │   └─► if (sampleIndex >= expectedDataCount)
        │       {
        │           resetSampleIndex(); // 重置时间戳
        │       }
        │
        └─► emit dataReceived(voltages, times);
                │
                └─► 发射信号给数据处理器/频谱分析器
```

### 关键函数详解

#### 1. ADC数据解析

```cpp
void UdpReceiver::onDataReceived()
{
    while (udpSocket->hasPendingDatagrams()) {
        QByteArray datagram;
        datagram.resize(udpSocket->pendingDatagramSize());
        udpSocket->readDatagram(datagram.data(), datagram.size());
        
        QVector<double> voltages;
        QVector<double> times;
        
        // 解析10-bit ADC值（2字节一个数据点）
        for (int i = 0; i < datagram.size() - 1; i += 2) {
            quint8 highByte = static_cast<quint8>(datagram[i]);
            quint8 lowByte = static_cast<quint8>(datagram[i + 1]);
            
            // 拼接10-bit值
            quint16 adc10bit = (static_cast<quint16>(highByte) << 8) | lowByte;
            adc10bit &= 0x3FF; // 保留低10位 (0-1023)
            
            // 转换为电压 (0-5V)
            double voltage = (adc10bit / 1023.0) * 5.0;
            
            // 计算时间戳（微秒）
            double time_us = (sampleIndex / sampleRate) * 1e6;
            
            voltages.append(voltage);
            times.append(time_us);
            
            sampleIndex++;
        }
        
        // 发射信号
        emit dataReceived(voltages, times);
    }
}
```

### 命令包格式

所有UDP命令包统一为 **8字节** 格式：

```text
字节索引:  0    1    2    3    4    5    6    7
         ┌────┬────┬────┬────┬────┬────┬────┬────┐
         │0x55│0xA5│ADDR│ P3 │ P2 │ P1 │ P0 │0xF0│
         └────┴────┴────┴────┴────┴────┴────┴────┘
         
说明：
- Byte 0: 帧头1 (0x55)
- Byte 1: 帧头2 (0xA5)
- Byte 2: 地址位 (命令类型, 8-bit)
- Byte 3-6: 参数位 (32-bit, 大端序: 高字节在前)
  - Byte 3: 参数最高字节 (bits 31-24)
  - Byte 4: 参数字节2 (bits 23-16)
  - Byte 5: 参数字节1 (bits 15-8)
  - Byte 6: 参数最低字节 (bits 7-0)
- Byte 7: 帧尾 (0xF0)
```

### 命令类型定义

根据下位机 `cmd_rx` 模块实现，命令地址映射如下：

| 命令 | 地址位 | 参数 (32-bit) | 说明 |
|------|--------|--------------|------|
| 重启采集 | 0 | 无 | 重新启动ADC采集 (RestartReq) |
| 通道选择 | 1 | [1:0]=channel (0-3) | 选择ADC通道 (ChannelSel) |
| 数据个数 | 2 | [31:0]=dataNum | 设置采样点数 (DataNum) |
| 分频系数 | 3 | [31:0]=divider | 设置ADC分频比 (ADC_Speed_Set) |
| 开始循环 | 4 | 无 | 开始循环发送数据 (while_data_en=1) |
| 停止循环 | 5 | 无 | 停止循环发送数据 (while_data_en=0) |
| DDS控制 | 6 | [5:3]=key, [2:0]=code | DDS波形与频率/幅度控制 |
| 手绘波形 | 7 | [9:0]=voltage | 发送手绘波形点 (dds_ram_data) |

**DDS控制命令 (地址6) 详解**：
- **参数格式**: `[5:3]` = 控制码 (key), `[2:0]` = 波形类型 (code)
- **波形类型** (低3位):
  - `3'b000` (0): 锯齿波
  - `3'b001` (1): 正弦波
  - `3'b010` (2): 方波
  - `3'b011` (3): 三角波
  - `3'b100` (4): 手绘波形
- **控制码** (高3位):
  - `3'b000` (0): 仅切换波形，不调整参数
  - `3'b010` (2): 频率减少
  - `3'b011` (3): 幅度减少
  - `3'b100` (4): 频率增加
  - `3'b101` (5): 幅度增加

### 命令发送流程

```text
UI用户操作
        │
        ▼
调用UdpSender命令函数
        │
        ├─► sendRestartCommand()         → ADDR = 0
        ├─► sendChannelSelectCommand()   → ADDR = 1, DATA = channel
        ├─► sendDataNumCommand()         → ADDR = 2, DATA = dataNum
        ├─► sendDividerCommand()         → ADDR = 3, DATA = divider
        ├─► sendStartLoopCommand()       → ADDR = 4
        ├─► sendStopLoopCommand()        → ADDR = 5
        ├─► sendWaveformCommand()        → ADDR = 6, DATA = waveformType
        ├─► sendFrequencyUpCommand()     → ADDR = 6, DATA = (4<<3)|type
        ├─► sendFrequencyDownCommand()   → ADDR = 6, DATA = (2<<3)|type
        ├─► sendAmplitudeUpCommand()     → ADDR = 6, DATA = (5<<3)|type
        └─► sendAmplitudeDownCommand()   → ADDR = 6, DATA = (3<<3)|type
                │
                ▼
        构建8字节命令包
                │
                ├─► packet[0] = 0x55 (帧头1)
                ├─► packet[1] = 0xA5 (帧头2)
                ├─► packet[2] = addressByte (命令类型)
                ├─► packet[3-6] = parameters (大端序, 高字节在前)
                └─► packet[7] = 0xF0 (帧尾)
                        │
                        ▼
                udpSocket->writeDatagram(packet, targetAddress, targetPort)
                        │
                        └─► FPGA cmd_rx模块接收并解析命令
```

```cpp
// 底层发送函数实现
void UdpSender::sendUdpPacket(quint8 cmdAddr, quint32 cmdData)
{
    QByteArray datagram;
    
    datagram.append(0x55);                        // 帧头1
    datagram.append(0xA5);                        // 帧头2
    datagram.append(cmdAddr);                     // 地址
    datagram.append((cmdData >> 24) & 0xFF);      // 参数高字节
    datagram.append((cmdData >> 16) & 0xFF);      // 参数字节2
    datagram.append((cmdData >> 8) & 0xFF);       // 参数字节1
    datagram.append(cmdData & 0xFF);              // 参数低字节
    datagram.append(0xF0);                        // 帧尾
    
    socket->writeDatagram(datagram, targetAddress, targetPort);
}
```

|-------------|-----------|------------|------|
| 0 | 1 | 50,000,000 | 默认最高速 |
| 1 | 2 | 25,000,000 | |
| 2 | 3 | 16,666,667 | |
| 4 | 5 | 10,000,000 | |
| 9 | 10 | 5,000,000 | |
| 49 | 50 | 1,000,000 | |
| 99 | 100 | 500,000 | |
| 499 | 500 | 100,000 | |
| 999 | 1000 | 50,000 | 低频信号测量 |

**计算公式**：
```
实际分频比 = 下位机分频比 + 1
采样率 = 50,000,000 / 实际分频比
```

### 类结构设计

#### 核心成员变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `serialPort` | `QSerialPort*` | 串口对象 |

| `emitTimer` | `QTimer*` | 定时发射定时器 (200ms) |
| `lastDuty` | int | 最近解析的占空比 |
| `lastHigh` | int | 最近解析的高电平时间 |
| `lastLow` | int | 最近解析的低电平时间 |
| `lastFreq` | double | 最近解析的频率 |
| `parserRegex` | QRegularExpression | 数据解析正则表达式 |

### 数据接收流程

```
下位机串口发送数据
        │
        │ 格式: "duty,highTime,lowTime,freq\n"
        │ 示例: "50,1000,1000,500.0\n"
        ▼
QSerialPort::readyRead() 信号
        │
        ▼
UARTReceiver::onReadyRead() 槽函数
        │
        ├─► 读取可用数据
        │   └─► buffer.append(serialPort->readAll())
        │
        ├─► 查找换行符 '\n'
        │   └─► int index = buffer.indexOf('\n');
        │
        ├─► 如果找到完整行
        │   ├─► 提取一行数据
        │   │   └─► line = buffer.left(index);
        │   │
        │   ├─► 使用正则表达式解析
        │   │   └─► QRegularExpression: "(\d+),(\d+),(\d+),([\d.]+)"
        │   │
        │   ├─► 提取4个值
        │   │   ├─► duty = match.captured(1).toInt()
        │   │   ├─► highTime = match.captured(2).toInt()
        │   │   ├─► lowTime = match.captured(3).toInt()
        │   │   └─► freq = match.captured(4).toDouble()
        │   │
        │   └─► 更新缓存变量
        │       ├─► lastDuty = duty
        │       ├─► lastHigh = highTime
        │       ├─► lastLow = lowTime
        │       └─► lastFreq = freq
        │
        └─► 移除已处理的数据
            └─► buffer.remove(0, index + 1);

定时器每200ms触发
        │
        ▼
UARTReceiver::emitParsed()
        │
        └─► emit parsedDataReady(lastDuty, lastHigh, lastLow, lastFreq);
                │
                └─► UI更新数字信号测量结果
```

### 关键函数实现

#### 1. 打开串口

```cpp
bool UARTReceiver::openPort(const QString &portName, qint32 baudRate)
{
    if (serialPort->isOpen()) {
        serialPort->close();
    }
    
    serialPort->setPortName(portName);
    serialPort->setBaudRate(baudRate);
    serialPort->setDataBits(QSerialPort::Data8);
    serialPort->setParity(QSerialPort::NoParity);
    serialPort->setStopBits(QSerialPort::OneStop);
    serialPort->setFlowControl(QSerialPort::NoFlowControl);
    
    if (serialPort->open(QIODevice::ReadOnly)) {
        // 启动定时器，每200ms发射一次最新数据
        emitTimer->start(200);
        return true;
    }
    
    return false;
}
```

#### 2. 数据解析

```cpp
void UARTReceiver::onReadyRead()
{
    buffer.append(serialPort->readAll());
    
    // 查找换行符
    int index;
    while ((index = buffer.indexOf('\n')) != -1) {
        QByteArray line = buffer.left(index).trimmed();
        buffer.remove(0, index + 1);
        
        // 正则表达式匹配: "num,num,num,num"
        QRegularExpressionMatch match = parserRegex.match(QString(line));
        if (match.hasMatch()) {
            lastDuty = match.captured(1).toInt();
            lastHigh = match.captured(2).toInt();
            lastLow = match.captured(3).toInt();
            lastFreq = match.captured(4).toDouble();
        }
    }
}
```

#### 3. 定时发射解析结果

```cpp
void UARTReceiver::emitParsed()
{
    if (lastDuty >= 0) { // 有效数据
        emit parsedDataReady(lastDuty, lastHigh, lastLow, lastFreq);
    }
}
```

## 数据包格式详解

### UDP接收数据包格式（FPGA → PC）

```
数据包大小: 1024字节 (512个10-bit ADC值)

字节布局:
┌────────┬────────┬────────┬────────┬─────┬────────┬────────┐
│ ADC0_H │ ADC0_L │ ADC1_H │ ADC1_L │ ... │ADC511_H│ADC511_L│
└────────┴────────┴────────┴────────┴─────┴────────┴────────┘
   Byte0   Byte1   Byte2   Byte3          Byte1022 Byte1023

每个ADC值占2字节（高字节在前，低字节在后）:
┌───────────────────────┬─────────────────────────────────┐
│    Byte 0 (High)      │       Byte 1 (Low)              │
├───┬───┬───┬───┬───┬───┼───┬───┬───┬───┬───┬───┬───┬───┤
│ x │ x │ x │ x │ x │ x │ D9│ D8│ D7│ D6│ D5│ D4│ D3│ D2│ D1│ D0│
└───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┴───┘
                          └──────── 10-bit ADC值 ──────┘

解析代码:
adc10bit = ((highByte << 8) | lowByte) & 0x3FF;
voltage = (adc10bit / 1023.0) * 5.0; // 0-5V
```

```text
数据包大小: 固定8字节

标准命令格式:
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐

 Byte0  Byte1  Byte2  Byte3  Byte4  Byte5  Byte6  Byte7
 帧头1  帧头2  地址   参数高字节           参数低字节  帧尾

示例1: 重启采集命令 (地址0)
┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
```

### UART接收数据格式（下位机 → PC）

```
数据格式: ASCII文本，以换行符结尾
模式: "占空比,高电平时间,低电平时间,频率\n"

示例1: 50%占空比，1000us高电平，1000us低电平，500Hz
"50,1000,1000,500.0\n"

示例2: 75%占空比，1500us高电平，500us低电平，500Hz
"75,1500,500,500.0\n"

解析正则表达式:
"(\d+),(\d+),(\d+),([\d.]+)"
  ↑     ↑     ↑       ↑
  duty  high  low    freq
```
