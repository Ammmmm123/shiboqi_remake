## 3. 频谱分析模式完整数据流

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                              FPGA硬件层                                      │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐                              │
│  │ ADC采样  │───►│ UDP发送  │───►│ 以太网   │                              │
│  └──────────┘    └──────────┘    └─────┬────┘                              │
└──────────────────────────────────────────┼──────────────────────────────────┘
                                           │
                                  UDP数据包 (电压数据)
                                           │
┌──────────────────────────────────────────▼──────────────────────────────────┐
│                              PC软件层                                        │
│                                                                              │
│  ┌────────────────────────────────────────────────────────────────────┐    │
│  │ UdpReceiver::onDataReceived()                                      │    │
│  │  └─► emit dataReceived(voltages, times)                            │    │
│  └─────────────────────────────────┬──────────────────────────────────┘    │
│                                    │                                        │
│                       Qt::QueuedConnection (跨线程)                         │
│                                    │                                        │
│  ┌─────────────────────────────────▼──────────────────────────────────┐    │
│  │ SpectrumAnalyzer::onDataReceived() [频谱分析线程]                  │    │
│  │                                                                     │    │
│  │  ┌───────────────────────────────────────────────────────┐         │    │
│  │  │ 1. 自动计算实际采样率（从时间戳）                     │         │    │
│  │  │    sampleRate = 1e6 / (times[1] - times[0])          │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 2. 去除DC分量                                          │         │    │
│  │  │    mean = avg(voltages)                               │         │    │
│  │  │    acVoltages[i] = voltages[i] - mean                 │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 3. 数据补零到2的幂次长度                               │         │    │
│  │  │    N = nextPowerOf2(voltages.size())                  │         │    │
│  │  │    complexData = [ac_0, ac_1, ..., 0, 0, ...]         │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 4. 执行FFT变换 (Cooley-Tukey算法)                     │         │    │
│  │  │    时间复杂度: O(N log N)                             │         │    │
│  │  │    fft(complexData)                                   │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 5. 计算幅度谱                                          │         │    │
│  │  │    magnitude[i] = abs(complexData[i]) * 2 / N         │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 6. 生成频率轴                                          │         │    │
│  │  │    frequencies[i] = i * sampleRate / N                │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 7. 寻找主频率峰值（跳过DC分量）                        │         │    │
│  │  │    dominantIndex = argmax(magnitude[1:])              │         │    │
│  │  │    dominantFrequency = frequencies[dominantIndex]     │         │    │
│  │  │    dominantAmplitude = magnitude[dominantIndex]       │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  ┌───────────────────────▼───────────────────────────────┐         │    │
│  │  │ 8. 寻找次频率峰值（第二大峰值，排除谐波）             │         │    │
│  │  │    secondIndex = argmax(magnitude, exclude_harmonic)  │         │    │
│  │  │    secondFrequency = frequencies[secondIndex]         │         │    │
│  │  │    secondAmplitude = magnitude[secondIndex]           │         │    │
│  │  └───────────────────────┬───────────────────────────────┘         │    │
│  │                          │                                         │    │
│  │  emit spectrumReady(result) {                                     │    │
│  │      dominantFrequency, dominantAmplitude,                        │    │
│  │      secondFrequency, secondAmplitude,                            │    │
│  │      frequencies[], amplitudes[]                                  │    │
│  │  }                                                                 │    │
│  └─────────────────────────┬───────────────────────────────────────────┘    │
│                            │                                                │
│                 Qt::QueuedConnection (跨线程回主线程)                       │
│                            │                                                │
│  ┌─────────────────────────▼───────────────────────────────────────────┐   │
│  │ shiboqi_remake::onSpectrumReady() [主线程 - UI更新]                 │   │
│  │                                                                      │   │
│  │  ┌────────────────────────────────────────────────────────┐         │   │
│  │  │ 缓存结果到 lastSpectrumResult                          │         │   │
│  │  └────────────────────────┬───────────────────────────────┘         │   │
│  │                           │                                         │   │
│  │  ┌────────────────────────▼───────────────────────────────┐         │   │
│  │  │ 延迟150ms后更新频谱图 (QTimer::singleShot)             │         │   │
│  │  │  ┌──────────────────────────────────────────┐          │         │   │
│  │  │  │ 1. 清空旧图形                            │          │         │   │
│  │  │  │    customPlot_spectrum->clearGraphs()    │          │         │   │
│  │  │  ├──────────────────────────────────────────┤          │         │   │
│  │  │  │ 2. 创建新图形                            │          │         │   │
│  │  │  │    addGraph() // 线条                    │          │         │   │
│  │  │  │    addGraph() // 填充区域                │          │         │   │
│  │  │  ├──────────────────────────────────────────┤          │         │   │
│  │  │  │ 3. 设置数据                              │          │         │   │
│  │  │  │    graph(0)->setData(freq, amp)          │          │         │   │
│  │  │  ├──────────────────────────────────────────┤          │         │   │
│  │  │  │ 4. 设置样式                              │          │         │   │
│  │  │  │    线条: 青色, 2px宽                     │          │         │   │
│  │  │  │    填充: 渐变色(青→透明)                 │          │         │   │
│  │  │  ├──────────────────────────────────────────┤          │         │   │
│  │  │  │ 5. 自动缩放Y轴                           │          │         │   │
│  │  │  │    yAxis->setRange(0, maxAmp * 1.1)      │          │         │   │
│  │  │  ├──────────────────────────────────────────┤          │         │   │
│  │  │  │ 6. 重绘图表                              │          │         │   │
│  │  │  │    customPlot_spectrum->replot()         │          │         │   │
│  │  │  │    [OpenGL加速]                          │          │         │   │
│  │  │  └──────────────────────────────────────────┘          │         │   │
│  │  └────────────────────────────────────────────────────────┘         │   │
│  │                                                                      │   │
│  │  ┌────────────────────────────────────────────────────────┐         │   │
│  │  │ 定时器每500ms更新数据标签 (减少跳动)                   │         │   │

│  │  └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘         │    │

**命令协议说明**：
- **帧结构**：固定8字节，帧头 `0x55 0xA5`，帧尾 `0xF0`
- **地址范围**：0-7（3位地址线）
- **参数格式**：32位大端序（高字节在前）
- **地址6特殊**：同时编码波形类型和控制操作，节省命令数量

## 6. 动态采样参数推荐完整流程 ⭐

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│                      动态采样参数推荐核心流程                                │
│                                                                              │
│  Step 1: 原始频率检测                                                       │
│  ┌────────────────────────────────────────────────────────────────────┐    │
│  │ FrequencyDetector::detectFrequency(voltages, times)                │    │
│  │  ├─► 计算信号均值                                                  │    │
│  │  ├─► 统计零交叉点                                                  │    │
│  │  └─► 计算频率 = (零交叉次数 / 2) / 总时间                        │    │
│  │       → rawFrequency                                               │    │
│  └─────────────────────────────┬──────────────────────────────────────┘    │
│                                │                                            │
│  Step 2: 滑动窗口平滑                                                       │
│  ┌─────────────────────────────▼──────────────────────────────────────┐    │
│  │ DataProcessor::getAveragedFrequency(rawFrequency)                  │    │
│  │  ├─► frequencyBuffer.push_back(rawFrequency)                       │    │
│  │  ├─► 保持窗口大小 = 80个样本                                       │    │
│  │  └─► 计算平均值                                                    │    │
│  │       → detectedFreq (平滑后的频率) ✓                             │    │
│  └─────────────────────────────┬──────────────────────────────────────┘    │
│                                │                                            │
│  Step 3: 采样质量评估                                                       │
│  ┌─────────────────────────────▼──────────────────────────────────────┐    │
│  │ FrequencyDetector::evaluateSamplingQuality(voltages, times)        │    │
│  │  ┌────────────────────────────────────────────────────────────┐    │    │
│  │  │ 计算当前采样率                                             │    │    │
│  │  │   currentSampleRate = voltages.size() / totalTime         │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 计算过采样倍数                                             │    │    │
│  │  │   oversamplingRatio = currentSampleRate / detectedFreq    │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 计算捕获周期数                                             │    │    │
│  │  │   capturedCycles = totalTime * detectedFreq               │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 判断质量是否充足                                           │    │    │
│  │  │   if (oversamplingRatio < 10x) → isAdequate = false      │    │    │
│  │  │   if (capturedCycles < 3) → isAdequate = false           │    │    │
│  │  └────────────────────────────────────────────────────────────┘    │    │
│  │       → qualityInfo { isAdequate, reason, ... }                    │    │
│  └─────────────────────────────┬──────────────────────────────────────┘    │
│                                │                                            │
│  Step 4: 动态推荐生成（质量不足时触发）                                    │
│  ┌─────────────────────────────▼──────────────────────────────────────┐    │
│  │ if (!qualityInfo.isAdequate)                                       │    │
│  │   DataProcessor::generateSamplingRecommendation(...)               │    │
│  │  ┌────────────────────────────────────────────────────────────┐    │    │
│  │  │ 策略1: 计算理想过采样倍数                                 │    │    │
│  │  │   minOversamplingRatio = 150x                             │    │    │
│  │  │   idealOversamplingRatio = 200x                           │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 策略2: 计算理想采样率                                     │    │    │
│  │  │   idealSampleRate = detectedFreq × 200                    │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 策略3: 计算理想分频比                                     │    │    │
│  │  │   BASE_CLOCK = 50 MHz (下位机基础时钟)                   │    │    │
│  │  │   idealDivider = BASE_CLOCK / idealSampleRate             │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 策略4: 调整分频比（确保过采样充足）                       │    │    │
│  │  │   限制范围: 1 ≤ divider ≤ 4000                           │    │    │
│  │  │   向上取整: divider = ceil(idealDivider)                 │    │    │
│  │  │   验证: while (oversampling < 150x && divider > 1)       │    │    │
│  │  │           divider--  // 降低分频比，提高采样率           │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 策略5: 固定采样点数                                       │    │    │
│  │  │   recommendedDataNum = 1500 (固定)                        │    │    │
│  │  │   计算可捕获周期数:                                       │    │    │
│  │  │     samplingTime = 1500 / recommendedSampleRate           │    │    │
│  │  │     actualCycles = samplingTime / signalPeriod            │    │    │
│  │  ├────────────────────────────────────────────────────────────┤    │    │
│  │  │ 策略6: 生成推荐说明                                       │    │    │
│  │  │   reason = "信号频率=XXX Hz, 过采样倍数=XXXx"            │    │    │
│  │  │           "分频比=XXX, 采样率=XXX Hz"                     │    │    │
│  │  │           "采样点数=1500, 可捕获约XXX个周期"              │    │    │
│  │  └────────────────────────────────────────────────────────────┘    │    │
│  │       → SamplingRecommendation { divider, sampleRate, ... }        │    │
│  └─────────────────────────────┬──────────────────────────────────────┘    │
│                                │                                            │
│  Step 5: 发送推荐信号                                                       │
│  ┌─────────────────────────────▼──────────────────────────────────────┐    │
│  │ emit samplingRecommendationReady(recommendation)                   │    │
│  │   → Qt::QueuedConnection (跨线程到UI)                              │    │
│  └─────────────────────────────┬──────────────────────────────────────┘    │
│                                │                                            │
│  Step 6: UI自动应用推荐                                                     │

### 7.1 滑动窗口频率平滑

```text
原始频率检测结果（可能抖动）
        │
        ▼
getAveragedFrequency(rawFrequency)
        │
        ├─► frequencyBuffer.push_back(rawFrequency)
        ├─► 保持窗口大小 = 80个样本
        └─► 计算平均值 = sum / 80
                │
                ▼
        平滑后的频率（稳定显示）✓
```

```text
原始数据 (voltages, times)
        │
        ▼
DataProcessor::processWaveformData()
        │
        ├─► 频率检测 + 平滑
        ├─► 质量评估 + 推荐
        ├─► 基本波形分析
        └─► 直接传递原始数据（不降采样）
                │
                ▼
        emit downsampledDataReady(voltages, times)
                │
                ▼
        UI绘图（QCustomPlot自动优化）
