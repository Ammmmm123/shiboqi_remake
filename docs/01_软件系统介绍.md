# 2.3 软件系统介绍

## 2.3.1 软件整体介绍

### 系统架构概览

本系统是一个基于Qt C++开发的FPGA调试器（示波器/频谱分析仪），采用PC端软件+FPGA硬件的分布式架构设计。

#### 关键架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                         PC端软件系统                              │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│  │ UI界面层     │  │ 数据处理层   │  │ 网络通信层   │          │
│  │ (Qt Widgets) │◄─┤ (多线程)     │◄─┤ (UDP/UART)   │          │
│  └──────────────┘  └──────────────┘  └──────┬───────┘          │
│                                               │                  │
└───────────────────────────────────────────────┼──────────────────┘
                                                │
                                    ┌───────────▼──────────┐
                                    │   网络/串口接口      │
                                    └───────────┬──────────┘
                                                │
┌───────────────────────────────────────────────▼──────────────────┐
│                      FPGA/下位机硬件系统                          │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐          │
│  │ ADC采样模块  │──┤ 数据缓存     │──┤ UDP发送模块  │          │
│  │ (10-bit)     │  │ (FIFO)       │  │              │          │
│  └──────────────┘  └──────────────┘  └──────────────┘          │
│  ┌──────────────┐  ┌──────────────┐                            │
│  │ DDS波形生成  │  │ 命令解析模块 │                            │
│  │              │  │ (UDP接收)    │                            │
│  └──────────────┘  └──────────────┘                            │
└─────────────────────────────────────────────────────────────────┘
```

### 系统主要功能模块

1. **示波器功能**
   - 实时波形显示（50MHz采样率）
   - 自动/手动缩放
   - 波形参数测量（频率、幅度、峰峰值、RMS等）
   - **动态采样参数推荐**：根据信号频率自动推荐最优分频比

2. **频谱分析功能**
   - FFT频谱分析
   - 主频率/次频率检测
   - 频谱图实时显示
   - 动态采样率自动计算

3. **DDS波形生成**
   - 预设波形（锯齿波、正弦波、方波、三角波）
   - 手绘自定义波形
   - 频率/幅度可调节
   - 一键控制（波形+频率/幅度）

4. **数字信号测量**
   - 占空比测量
   - 高/低电平时间测量
   - 频率计算
   - 数字波形显示

### 技术特点

- **多线程架构**：UI线程、数据处理线程、频谱分析线程独立运行，互不阻塞
- **高性能绘图**：使用QCustomPlot绘图库
- **智能采样推荐**：80个样本滑动窗口平均频率，自动评估采样质量并推荐最优参数（150x~200x过采样倍数）
- **实时性保证**：LIFO队列机制，优先显示最新数据
- **跨平台**：基于Qt框架，支持Windows/Linux/macOS

### 开发环境

- **编程语言**：C++17
- **GUI框架**：Qt 5/6 (Widgets)
- **绘图库**：QCustomPlot 2.x
- **通信协议**：UDP、UART
- **编译器**：MSVC/GCC/Clang

### 数据流概览

#### 示波器模式数据流

```
FPGA (ADC采样) 
    │
    │ UDP数据包 (10-bit ADC值，512个/包)
    ▼
UdpReceiver::onDataReceived()
    │
    │ 电压转换 (0-1023 → 0-5V) + 时间戳计算
    ▼
DataProcessor::processWaveformData() [独立线程]
    │
    ├─► 1. 频率检测（零交叉法） + 滑动窗口平均（80个样本）
    │
    ├─► 2. 采样质量评估（FrequencyDetector）
    │   ├─► 计算过采样倍数
    │   ├─► 检查周期数
    │   └─► 判断质量是否充足
    │
    ├─► 3. 动态采样参数推荐 ⭐（质量不足时触发）
    │   ├─► 计算理想分频比（基于150x~200x过采样）
    │   ├─► 验证并调整范围（1~4000）
    │   ├─► 固定采样点数=1500
    │   └─► samplingRecommendationReady(rec) ──► UI自动应用
    │
    ├─► 4. 波形分析（频率、幅度、峰峰值、RMS等）
    │   └─► analysisReady(result) ──► UI显示参数
    │
    └─► 5. 输出原始数据（不降采样）
        └─► downsampledDataReady(voltages, times) ──► UI绘图
```

#### 频谱分析模式数据流

```
FPGA (ADC采样)
    │
    │ UDP数据包
    ▼
UdpReceiver::onDataReceived()
    │
    │ 电压转换 + 时间戳计算
    ▼
SpectrumAnalyzer::onDataReceived() [独立线程]
    │
    ├─► FFT变换
    │
    ├─► 主频/次频检测
    │
    └─► spectrumReady(result) ──► UI绘制频谱图
```

#### 命令发送数据流

```
UI (用户操作)
    │
    ├─► 重启采集           → 地址0  (无参数)
    ├─► 通道选择           → 地址1  (channel: 0-3)
    ├─► 数据个数设置       → 地址2  (dataNum: 32-bit)
    ├─► 分频系数设置       → 地址3  (divider: 32-bit)
    ├─► 开始/停止循环      → 地址4/5 (无参数)
    ├─► DDS波形选择        → 地址6  (waveType: 0-4)
    ├─► DDS频率/幅度调节   → 地址6  ([5:3]=key, [2:0]=waveType)
    └─► 手绘波形数据       → 地址7  (voltage: 10-bit)
            │
            ▼
        UdpSender::sendXxxCommand()
            │
            │ 8字节命令包: {0x55, 0xA5, ADDR, P3, P2, P1, P0, 0xF0}
            │ （大端序：高字节在前）
            ▼
        FPGA cmd_rx模块（命令解析）
            │
            └─► 根据地址位执行对应操作
```

**说明**：
- 帧头：`0x55, 0xA5`（固定）
- 帧尾：`0xF0`（固定）
- 参数：大端序，4字节（Byte3=最高字节，Byte6=最低字节）
- 地址6特殊编码：同时控制波形类型和频率/幅度调节

### 关键设计模式

1. **信号-槽机制**：Qt框架核心，用于模块间解耦通信
2. **生产者-消费者模式**：UDP接收线程生产数据，处理线程消费数据
3. **LIFO队列**：优先显示最新数据，丢弃旧数据
4. **线程池模式**：数据处理线程、频谱分析线程独立运行
5. **策略模式**：多种频率检测算法（过零、自相关、FFT）

---

### 性能优化措施

1. **高性能绘图**：QCustomPlot绘图库
2. **滑动窗口频率平滑**：80个样本平均，减少抖动
3. **动态采样优化**：根据信号频率自动推荐最优分频比（150x~200x过采样）
4. **LIFO机制**：丢弃旧数据，保证实时性
5. **线程隔离**：UI与数据处理分离，避免界面卡顿
6. **异步信号**：Qt::QueuedConnection跨线程通信
