### 关键算法详解

#### 1. 完整数据处理流程（实际代码）

```cpp
void DataProcessor::processWaveformData(const QVector<double>& voltages, 
                                        const QVector<double>& times)
{
    // ========== 1. 数据有效性检查 ==========
    if (voltages.isEmpty() || times.isEmpty()) {
        qWarning() << "Empty data received";
        return;
    }
    
    // ========== 2. 频率检测与滑动窗口平均 ==========
    // 检测原始频率
    double rawFrequency = FrequencyDetector::detectFrequency(voltages, times);
    
    // 使用滑动窗口（80个样本）平均频率，提高稳定性
    double detectedFreq = getAveragedFrequency(rawFrequency);
    
    // ========== 3. 采样质量评估 ==========
    SamplingQualityInfo qualityInfo = 
        FrequencyDetector::evaluateSamplingQuality(voltages, times);
    
    // 更新评估结果中的频率为平均后的频率
    qualityInfo.detectedFrequency = detectedFreq;
    
    // ========== 4. 动态采样参数推荐（核心功能）⭐ ==========
    if (!qualityInfo.isAdequate) {
        // 采样质量不足，生成推荐参数
        SamplingRecommendation recommendation = generateSamplingRecommendation(
            detectedFreq, 
            sampleRate, 
            qualityInfo  // 传入评估结果作为参考
        );
        
        // 发送推荐到 UI，由用户决定是否应用
        emit samplingRecommendationReady(recommendation);
    }
    
    // ========== 5. 基本波形分析 ==========
    WaveformAnalysisResult result;
    result.frequency = detectedFreq;
    
    if (!voltages.isEmpty()) {
        result.maxValue = *std::max_element(voltages.begin(), voltages.end());
        result.minValue = *std::min_element(voltages.begin(), voltages.end());
        result.peakToPeak = result.maxValue - result.minValue;
        result.amplitude = result.peakToPeak / 2.0;
        
        // RMS 有效值
        double sumSquares = 0.0;
        for (double v : voltages) {
            sumSquares += v * v;
        }
        result.rmsValue = std::sqrt(sumSquares / voltages.size());
    }
    
    emit analysisReady(result);
    
    // ========== 6. 输出原始数据（不降采样）==========
    emit downsampledDataReady(voltages, times);
}
```

#### 2. 动态采样参数推荐算法 ⭐（核心功能）

**目标**：根据检测到的信号频率，自动计算最优的下位机采样参数（分频比、采样率）

**策略**：
- **高频信号**：降低分频比，提高采样率，保证过采样倍数
- **低频信号**：增大分频比，降低采样率，在固定采样点数内捕获更多周期
- **过采样倍数**：150x~200x，确保波形平滑细腻
- **采样点数**：固定1500点，平衡内存与传输效率

```cpp
SamplingRecommendation DataProcessor::generateSamplingRecommendation(
    double signalFreq, 
    double currentSampleRate, 
    const SamplingQualityInfo &qualityInfo)
{
    SamplingRecommendation rec;
    
    if (signalFreq <= 0) {
        rec.reason = "无法检测到有效频率";
        return rec;
    }
    
    // ========== 采样率推荐策略 ==========
    const double minOversamplingRatio = 150.0;   // 最小过采样倍数
    const double idealOversamplingRatio = 200.0; // 理想过采样倍数
    
    // 检查是否因为周期数不足导致质量问题
    bool needMoreCycles = qualityInfo.reason.contains("周期");
    
    // 计算理想采样率
    double idealSampleRate = signalFreq * idealOversamplingRatio;
    
    // 下位机基础时钟频率
    const double BASE_CLOCK = 50000000.0; // 50MHz
    
    // 计算理想分频比
    double idealDivider = BASE_CLOCK / idealSampleRate;
    
    // 如果 FrequencyDetector 建议需要更多周期，参考其推荐分频比
    if (needMoreCycles && qualityInfo.recommendedDivider > 0) {
        double freqDetectorDivider = static_cast<double>(qualityInfo.recommendedDivider);
        if (freqDetectorDivider > idealDivider) {
            idealDivider = freqDetectorDivider;
        }
    }
    
    // 限制分频范围：1~4000
    if (idealDivider < 1.0) idealDivider = 1.0;
    else if (idealDivider > 4000.0) idealDivider = 4000.0;
    
    // 向上取整（低频信号宁可分频比大一点）
    rec.recommendedDivider = static_cast<quint32>(std::ceil(idealDivider));
    if (rec.recommendedDivider < 1) rec.recommendedDivider = 1;
    if (rec.recommendedDivider > 4000) rec.recommendedDivider = 4000;
    
    // 计算实际采样率
    rec.recommendedSampleRate = BASE_CLOCK / rec.recommendedDivider;
    
    // 验证过采样倍数
    double actualOversampling = rec.recommendedSampleRate / signalFreq;
    
    // 如果过采样倍数低于最小要求，降低分频比（提高采样率）
    while (actualOversampling < minOversamplingRatio && rec.recommendedDivider > 1) {
        rec.recommendedDivider--;
        rec.recommendedSampleRate = BASE_CLOCK / rec.recommendedDivider;
        actualOversampling = rec.recommendedSampleRate / signalFreq;
    }
    
    // 生成推荐说明
    if (rec.recommendedSampleRate < signalFreq * minOversamplingRatio) {
        rec.reason = QString("⚠️ 警告：信号频率(%1 Hz)过高，推荐采样率(%2 Hz)可能不足\n"
                            "建议：降低信号频率或接受较低的采样质量")
                     .arg(signalFreq, 0, 'f', 2)
                     .arg(rec.recommendedSampleRate, 0, 'f', 0);
    } else {
        rec.reason = QString("✅ 信号频率=%1 Hz，过采样倍数=%2x (波形平滑)\n"
                            "分频比=%3，采样率=%4 Hz")
                     .arg(signalFreq, 0, 'f', 2)
                     .arg(actualOversampling, 0, 'f', 1)
                     .arg(rec.recommendedDivider)
                     .arg(rec.recommendedSampleRate, 0, 'f', 0);
    }
    
    // ========== 采样点数固定策略 ==========
    rec.recommendedDataNum = 1500;  // 固定1500点
    
    // 计算能捕获的周期数
    double signalPeriod = 1.0 / signalFreq;
    double samplingTime = rec.recommendedDataNum / rec.recommendedSampleRate;
    double actualCycles = samplingTime / signalPeriod;
    
    rec.reason += QString("\n采样点数=1500（固定），可捕获约%1个完整周期")
                  .arg(actualCycles, 0, 'f', 1);
    
    return rec;
}
```

**推荐算法示例**：

| 信号频率 | 理想采样率 | 推荐分频比 | 实际采样率 | 过采样倍数 | 捕获周期数 |
|---------|-----------|-----------|-----------|-----------|-----------|
| 100 Hz | 20 kHz | 2500 | 20 kHz | 200x | 3.0 周期 |
| 1 kHz | 200 kHz | 250 | 200 kHz | 200x | 7.5 周期 |
| 10 kHz | 2 MHz | 25 | 2 MHz | 200x | 30 周期 |
| 100 kHz | 20 MHz | 3 | 16.7 MHz | 167x | 251 周期 |

#### 3. 滑动窗口频率平滑

**目的**：消除单次检测的抖动，提供稳定的频率值

```cpp
double DataProcessor::getAveragedFrequency(double newFrequency)
{
    const int WINDOW_SIZE = 80;  // 窗口大小
    
    // 添加新频率
    frequencyBuffer.push_back(newFrequency);
    
    // 保持窗口大小
    if (frequencyBuffer.size() > WINDOW_SIZE) {
        frequencyBuffer.pop_front();
    }
    
    // 计算平均值
    double sum = 0.0;
    for (double freq : frequencyBuffer) {
        sum += freq;
    }
    
    return sum / frequencyBuffer.size();
}
```

**效果**：80个样本平均，频率显示更加稳定，减少推荐参数的频繁变化。

#### 4. 频率检测与采样质量评估算法（FrequencyDetector）

**功能**：检测信号频率并评估采样率是否满足 Nyquist 定理

```cpp
// 检测信号主频率（基于零交叉点）
double FrequencyDetector::detectFrequency(const QVector<double>& voltages, 
                                          const QVector<double>& times)
{
    if (voltages.size() < 3) return 0.0;
    
    // 计算信号均值，用于判断零交叉
    double mean = 0.0;
    for (double v : voltages) mean += v;
    mean /= voltages.size();
    
    // 统计零交叉点数量
    int zeroCrossings = 0;
    for (int i = 1; i < voltages.size(); ++i) {
        bool prevAboveMean = (voltages[i-1] > mean);
        bool currAboveMean = (voltages[i] > mean);
        
        if (prevAboveMean != currAboveMean) {
            zeroCrossings++;
        }
    }
    
    // 频率 = 零交叉次数 / (2 * 总时间)
    // 因为一个完整周期有两次零交叉
    double totalTime = times.last() - times.first();
    double frequency = (zeroCrossings / 2.0) / totalTime;
    
    return frequency;
}

// 评估采样质量并给出建议
FrequencyDetector::SamplingQuality 
FrequencyDetector::evaluateSamplingQuality(const QVector<double>& voltages, 
                                           const QVector<double>& times)
{
    SamplingQuality result;
    
    // 1. 检测信号主频率
    double signalFreq = detectFrequency(voltages, times);
    result.detectedFrequency = signalFreq;
    
    // 2. 计算当前采样率
    double totalTime = times.last() - times.first();
    double currentSamplingRate = voltages.size() / totalTime;
    result.currentSamplingRate = currentSamplingRate;
    
    // 3. 根据 Nyquist 定理，采样率应至少为信号频率的 2 倍
    // 实际建议使用 5 倍以上以获得更好的波形还原
    double minRequiredRate = signalFreq * 2.0;  // Nyquist 最小值
    result.recommendedSamplingRate = signalFreq * 5.0;  // 推荐值
    
    // 4. 判断是否欠采样
    result.isUndersampled = (currentSamplingRate < minRequiredRate);
    
    return result;
}
```

**SamplingQuality 结构体定义**：

```cpp
struct SamplingQuality {
    double detectedFrequency;        // 检测到的信号频率 (Hz)
    double currentSamplingRate;      // 当前采样率 (Hz)
    double recommendedSamplingRate;  // 推荐采样率 (Hz)
    bool isUndersampled;             // 是否欠采样（违反 Nyquist 定理）
};

## 频率检测器 (FrequencyDetector)

### 核心功能

- **主频率检测**：通过零交叉点分析检测信号的基频
- **采样质量评估**：判断当前采样率是否满足 Nyquist 采样定理
- **采样率建议**：根据检测到的信号频率，计算推荐的最小采样率

### 零交叉检测法（实际实现算法）

**原理**：统计信号穿越均值线的次数，计算周期频率

```cpp
double FrequencyDetector::detectFrequency(const QVector<double>& voltages, 
                                          const QVector<double>& times)
{
    if (voltages.size() < 3) return 0.0;
    
    // 1. 计算信号均值
    double mean = 0.0;
    for (double v : voltages) mean += v;
    mean /= voltages.size();
    
    // 2. 统计零交叉点
    int zeroCrossings = 0;
    for (int i = 1; i < voltages.size(); ++i) {
        bool prevAboveMean = (voltages[i-1] > mean);
        bool currAboveMean = (voltages[i] > mean);
        
        // 检测状态变化（穿越均值线）
        if (prevAboveMean != currAboveMean) {
            zeroCrossings++;
        }
    }
    
    // 3. 计算频率
    // 一个完整周期包含2次零交叉（上升沿+下降沿）
    double totalTime = times.last() - times.first();
    double frequency = (zeroCrossings / 2.0) / totalTime;
    
    return frequency;
}
```

**优点**：
- 计算速度快，实时性好
- 适用于正弦波、三角波等周期信号
- 对噪声有一定容忍度

**局限性**：

- 对复杂波形（如含谐波）精度较低
- 需要信号有明显的周期性

### UI响应推荐

当 `DataProcessor` 检测到采样质量不足时，会发出 `samplingRecommendationReady` 信号，UI接收后自动应用推荐参数：

```cpp
void shiboqi_remake::onSamplingRecommendationReady(const SamplingRecommendation &recommendation)
{
    // 记录推荐信息
    qDebug() << "收到采样参数推荐";
    qDebug() << "推荐分频比：" << recommendation.recommendedDivider;
    qDebug() << "推荐采样率：" << recommendation.recommendedSampleRate;
    qDebug() << "推荐理由：" << recommendation.reason;
    
    // 计算下位机实际分频比（需要减1）
    quint32 actualDivider = recommendation.recommendedDivider - 1;
    
    // 计算实际采样率
    double actualSampleRate = 50000000.0 / recommendation.recommendedDivider;
    
    // 自动发送新的采样参数到下位机
    if (udpSender) {
        // 先停止采集
        udpSender->sendStopLoopCommand();
        QThread::msleep(50);
        
        // 设置新的分频比
        udpSender->setDivider(actualDivider);
        udpSender->sendDividerCommand();
        QThread::msleep(50);
        
        // 重启采集（使用新参数）
        udpSender->sendRestartCommand();
        
        // 更新UI显示
        ui->label_sampleRate->setText(
            QString("采样率: %1 kHz").arg(actualSampleRate / 1000.0, 0, 'f', 1)
        );
        
        // 显示推荐理由（可选）
        statusBar()->showMessage(recommendation.reason, 5000);
    }
}
```

## 性能优化措施

### 1. 滑动窗口频率平滑（80个样本）

**问题**：单次频率检测结果可能抖动

**解决**：使用80个样本的滑动窗口取平均值

**效果**：
- 频率显示稳定
- 减少推荐参数的频繁变化
- 提升用户体验

### 2. 直接传递原始数据（无降采样）

**策略**：将原始数据直接发送到 UI，由 `QCustomPlot` 自动优化显示

**效果**：
- 保留完整波形细节
- 绘图库自动处理显示优化
- 简化处理逻辑

### 3. 采样质量评估触发推荐

**机制**：仅在 `FrequencyDetector` 判断质量不足时才生成推荐

```cpp
if (!qualityInfo.isAdequate) {
    SamplingRecommendation recommendation = generateSamplingRecommendation(...);
    emit samplingRecommendationReady(recommendation);
}
```

**好处**：
- 避免不必要的推荐
- 减少UI干扰
- 仅在真正需要时调整参数
