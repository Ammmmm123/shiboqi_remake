# UI界面模块设计说明

## 模块概述

**文件位置**：`src/ui/shiboqi_remake.cpp` 和 `src/ui/shiboqi_remake.h`

**主要功能**：
- 用户交互界面（示波器、频谱分析、DDS设置、数字信号测量）
- 参数配置（IP地址、端口、采样点数等）
- 实时波形/频谱显示
- 测量结果显示

## 关键功能流程图

### 1. 监听开始流程

```
用户点击"开始监听"按钮
        │
        ▼
on_listenButton_toggled(true)
        │
        ├─► 创建数据处理线程 (DataProcessorThread)
        │   └─► 连接信号：
        │       - dataReceived → DataProcessor::processWaveformData
        │       - analysisReady → UI显示分析结果
        │       - downsampledDataReady → UI绘图
        │       - samplingRecommendationReady → 自动调整分频比
        │
        ├─► 创建频谱分析线程 (SpectrumAnalyzer)
        │   └─► 连接信号：
        │       - dataReceived → SpectrumAnalyzer::onDataReceived
        │       - spectrumReady → UI绘制频谱图
        │
        ├─► 设置默认分频比为1 (50MHz采样率)
        │   └─► udpSender->setDivider(0) // 下位机分频比 = 0
        │
        ├─► 同步采样率到各模块
        │   ├─► udpReceiver->setSampleRate(50MHz)
        │   ├─► dataProcessor->setSamplingConfig(dataNum, 50MHz)
        │   └─► 频谱分析器从时间戳自动计算采样率
        │
        └─► udpReceiver->startListening()
                │
                └─► 开始接收UDP数据
```

### 2. 监听停止流程

```
用户点击"停止监听"按钮
        │
        ▼
on_listenButton_toggled(false)
        │
        ├─► 立即断开信号连接（防止新数据进入）
        │   ├─► disconnect(udpReceiver, dataReceived)
        │   └─► 各处理器停止接收新数据
        │
        ├─► udpReceiver->stopListening()
        │
        ├─► 清空LIFO队列
        │   ├─► plotVoltages.clear()
        │   └─► plotTimes.clear()
        │
        ├─► 快速停止数据处理线程（不等待队列处理完）
        │   └─► dataProcessorThread->stop()
        │
        └─► 快速停止频谱分析线程
            └─► spectrumThread->quit() + wait()
```

### 3. 示波器绘图流程

```
DataProcessor [独立线程]
        │
        │ 完成降采样
        ▼
emit downsampledDataReady(voltages, times)
        │
        │ Qt::QueuedConnection (跨线程)
        ▼
shiboqi_remake::onDownsampledDataReady() [主线程]
        │
        ├─► LIFO队列替换
        │   ├─► plotVoltages = voltages (丢弃旧数据)
        │   └─► plotTimes = times
        │
        └─► 自动缩放坐标轴（仅首次，未手动缩放时）
                │
                └─► customPlot->xAxis->setRange(0, maxTime)
                    customPlot->yAxis->setRange(minV, maxV)
        
定时器每50ms触发
        │
        ▼
shiboqi_remake::updatePlot()
        │
        ├─► 检查是否为示波器模式
        │
        ├─► 时间戳平移（第一个点为t=0）
        │   └─► adjustedTimes[i] = plotTimes[i] - plotTimes[0]
        │
        ├─► customPlot->graph(0)->setData(adjustedTimes, plotVoltages)
        │
        └─► customPlot->replot()  // OpenGL加速绘图
```

### 4. 频谱分析绘图流程

```
SpectrumAnalyzer [独立线程]
        │
        │ 完成FFT分析
        ▼
emit spectrumReady(result)
        │
        │ Qt::QueuedConnection (跨线程)
        ▼
shiboqi_remake::onSpectrumReady() [主线程]
        │
        ├─► 缓存结果到 lastSpectrumResult
        │
        └─► 150ms后更新频谱图 (QTimer::singleShot)
                │
                ├─► 清空旧graph并创建新的填充区域
                │   └─► customPlot_spectrum->clearGraphs()
                │       customPlot_spectrum->addGraph() // 线条
                │       customPlot_spectrum->addGraph() // 填充区域
                │
                ├─► 设置数据
                │   ├─► graph(0)->setData(frequencies, amplitudes)
                │   └─► graph(1)->setData(frequencies, baselineAmplitudes)
                │
                ├─► 自动缩放Y轴
                │   └─► yAxis->setRange(0, maxAmplitude * 1.1)
                │
                └─► customPlot_spectrum->replot()

定时器每500ms触发 (spectrumLabelUpdateTimer)
        │
        ▼
更新频谱数据标签
        │
        ├─► Frequency_4_in->setText(dominantFrequency)
        ├─► Amplitude_4_in->setText(dominantAmplitude)
        └─► (其他测量参数)
```

## 事件过滤器设计

### eventFilter() 函数处理的事件

#### 1. 示波器鼠标滚轮缩放

```cpp
if (obj == customPlot && event->type() == QEvent::Wheel)
{
    QWheelEvent *wheelEvent = static_cast<QWheelEvent*>(event);
    
    // Ctrl + 滚轮：缩放Y轴（保持0居中）
    if (wheelEvent->modifiers() & Qt::ControlModifier) {
        double factor = (wheelEvent->angleDelta().y() > 0) ? 0.85 : 1.15;
        scaleYAxis(customPlot, factor, wheelEvent->pos());
        hasUserZoomed = true; // 标记为手动缩放
    }
    // Shift + 滚轮：缩放X轴（固定左边界为0）
    else if (wheelEvent->modifiers() & Qt::ShiftModifier) {
        double factor = (wheelEvent->angleDelta().y() > 0) ? 0.85 : 1.15;
        scaleXAxis(customPlot, factor, wheelEvent->pos(), plotTimes);
        hasUserZoomed = true;
    }
    
    customPlot->replot();
    return true; // 事件已处理
}
```

#### 2. DDS手绘波形的鼠标事件

```cpp
if (obj == ui->boxingxianshi && isHandDrawMode)
{
    QCustomPlot *drawPlot = ui->boxingxianshi;
    
    if (event->type() == QEvent::MouseButtonPress) {
        isDrawing = true;
        handDrawnPoints.clear(); // 清空旧点
    }
    else if (event->type() == QEvent::MouseMove && isDrawing) {
        QMouseEvent *mouseEvent = static_cast<QMouseEvent*>(event);
        
        // 将屏幕坐标转换为绘图坐标
        double x = drawPlot->xAxis->pixelToCoord(mouseEvent->pos().x());
        double y = drawPlot->yAxis->pixelToCoord(mouseEvent->pos().y());
        
        // 限制范围：x∈[0,1], y∈[0,1023]
        x = qBound(0.0, x, 1.0);
        y = qBound(0.0, y, 1023.0);
        
        handDrawnPoints.append(QPointF(x, y));
        
        // 实时显示
        drawPlot->graph(0)->setData(...);
        drawPlot->replot();
    }
    else if (event->type() == QEvent::MouseButtonRelease) {
        isDrawing = false;
    }
    
    return true;
}
```

## 性能优化措施

### 1. OpenGL硬件加速

```cpp
customPlot->setOpenGl(true);  // 启用OpenGL后端
```

### 2. LIFO队列机制

```cpp
// 最新数据直接替换，丢弃旧数据（LIFO）
void shiboqi_remake::onDownsampledDataReady(const QVector<double> &voltages, 
                                            const QVector<double> &times)
{
    plotVoltages = voltages;  // 直接赋值，不累积
    plotTimes = times;
}
```

### 3. 定时器频率控制

- **示波器更新**：50ms (20fps) - `updateTimer`
- **频谱标签更新**：500ms (2fps) - `spectrumLabelUpdateTimer`
- **频谱图更新**：150ms延迟 - `QTimer::singleShot`

### 4. 模式切换时的资源管理

```cpp
// 切换到示波器模式时
connect(ui->navButton_oscilloscope, &QPushButton::clicked, [this]() {
    isSpectrumMode = false;
    
    // 停止频谱相关定时器
    if (spectrumLabelUpdateTimer) spectrumLabelUpdateTimer->stop();
    
    // 断开频谱分析器连接，减少CPU占用
    if (spectrumAnalyzer) disconnect(udpReceiver, dataReceived, ...);
    
    // 重新连接数据处理器
    if (dataProcessor) connect(udpReceiver, dataReceived, ...);
    
    // 启动示波器更新定时器
    if (updateTimer) updateTimer->start(50);
});
```

## 信号槽连接总结

### UDP接收相关

| 信号 | 槽函数 | 说明 |
|------|-------|------|
| `UdpReceiver::dataReceived` | `DataProcessor::processWaveformData` | 原始数据送入处理器 |
| `UdpReceiver::dataReceived` | `SpectrumAnalyzer::onDataReceived` | 原始数据送入频谱分析器 |
| `UdpReceiver::bindFailed` | `shiboqi_remake::onUdpBindFailed` | UDP绑定失败处理 |

### 数据处理相关

| 信号 | 槽函数 | 说明 |
|------|-------|------|
| `DataProcessor::analysisReady` | `shiboqi_remake::onAnalysisReady` | 显示波形参数 |
| `DataProcessor::downsampledDataReady` | `shiboqi_remake::onDownsampledDataReady` | 更新绘图队列 |
| `DataProcessor::samplingRecommendationReady` | `shiboqi_remake::onSamplingRecommendationReady` | 自动调整分频比 |

### 频谱分析相关

| 信号 | 槽函数 | 说明 |
|------|-------|------|
| `SpectrumAnalyzer::spectrumReady` | `shiboqi_remake::onSpectrumReady` | 更新频谱图 |

### UART接收相关

| 信号 | 槽函数 | 说明 |
|------|-------|------|
| `UARTReceiver::parsedDataReady` | `shiboqi_remake::onParsedSerialData` | 更新数字信号测量结果 |

### 手绘波形发送相关

| 信号 | 槽函数 | 说明 |
|------|-------|------|
| `WaveformSenderThread::progressUpdated` | `shiboqi_remake::onWaveformSendProgress` | 显示发送进度 |
| `WaveformSenderThread::sendingCompleted` | `shiboqi_remake::onWaveformSendCompleted` | 发送成功提示 |
| `WaveformSenderThread::sendingFailed` | `shiboqi_remake::onWaveformSendFailed` | 发送失败提示 |
