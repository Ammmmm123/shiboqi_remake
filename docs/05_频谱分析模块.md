# 频谱分析模块设计说明

## 模块概述

**文件位置**：`src/analysis/spectrum_analyzer.cpp/h`

**主要功能**：

- FFT频谱分析（快速傅里叶变换）
- 主频率/次频率检测
- 频谱图实时显示
- 自动采样率计算（从时间戳）

### 频谱分析流程图

```text
UdpReceiver::dataReceived(voltages, times)
        │
        │ Qt::QueuedConnection (跨线程)
        ▼
SpectrumAnalyzer::onDataReceived() [独立线程]
        │
        ├─► 临时存储数据
        │   ├─► accumulatedVoltages = voltages
        │   └─► accumulatedTimes = times
        │
        ├─► 执行FFT分析
        │   └─► performFFT()
        │       │
        │       ├─► 1. 计算实际采样率（从时间戳）
        │       │   └─► sampleRate = 1e6 / (times[1] - times[0])
        │       │
        │       ├─► 2. 去除DC分量（减去平均值）
        │       │   └─► voltage_i = voltage_i - mean
        │       │
        │       ├─► 3. 数据补零到2的幂次长度
        │       │   └─► N = nextPowerOf2(voltages.size())
        │       │
        │       ├─► 4. 执行FFT变换
        │       │   └─► fft(complexData)
        │       │       └─► Cooley-Tukey算法
        │       │
        │       ├─► 5. 计算幅度谱
        │       │   └─► magnitude[i] = abs(complexData[i]) * 2 / N
        │       │
        │       ├─► 6. 生成频率轴
        │       │   └─► freq[i] = i * sampleRate / N
        │       │
        │       ├─► 7. 寻找主频率峰值（跳过DC分量）
        │       │   └─► dominantFrequency, dominantAmplitude
        │       │
        │       └─► 8. 寻找次频率峰值（第二大峰值）
        │           └─► secondFrequency, secondAmplitude
        │
        ├─► 增加分析计数
        │   └─► analysisCount++
        │
        └─► 发射频谱结果
            └─► emit spectrumReady(result)
                    │
                    └─► UI更新频谱图和数据标签
```

### 关键算法详解

#### 1. FFT算法实现（Cooley-Tukey）

**时间复杂度**：O(N log N)

**空间复杂度**：O(N)

```cpp
void SpectrumAnalyzer::fft(QVector<std::complex<double>> &data)
{
    int N = data.size();
    
    // 递归终止条件
    if (N <= 1) return;
    
    // 分离奇偶项
    QVector<std::complex<double>> even(N / 2);
    QVector<std::complex<double>> odd(N / 2);
    
    for (int i = 0; i < N / 2; i++) {
        even[i] = data[2 * i];
        odd[i] = data[2 * i + 1];
    }
    
    // 递归计算FFT
    fft(even);
    fft(odd);
    
    // 合并结果
    const double PI = 3.14159265358979323846;
    for (int k = 0; k < N / 2; k++) {
        std::complex<double> t = std::polar(1.0, -2.0 * PI * k / N) * odd[k];
        data[k] = even[k] + t;
        data[k + N / 2] = even[k] - t;
    }
}
```

#### 2. 自动采样率计算（从时间戳）

**关键创新**：不依赖软件配置，直接从时间戳计算实际采样率

```cpp
void SpectrumAnalyzer::performFFT()
{
    if (accumulatedVoltages.size() < 10) return;
    
    // 从时间戳计算实际采样率
    double deltaTime_us = accumulatedTimes[1] - accumulatedTimes[0];
    double actualSampleRate = 1e6 / deltaTime_us; // us -> Hz
    
    qDebug() << "频谱分析：自动检测采样率 =" << actualSampleRate << "Hz";
    
    // ... 继续FFT分析
}
```

**优势**：

- 无需手动配置采样率
- 自动适应下位机分频比变化
- 提高频谱分析精度

#### 3. DC分量去除

**原理**：去除信号的直流偏置，提高FFT分析精度

```cpp
// 计算平均值
double mean = 0.0;
for (double v : accumulatedVoltages) {
    mean += v;
}
mean /= accumulatedVoltages.size();

// 去除DC分量
QVector<double> acVoltages;
for (double v : accumulatedVoltages) {
    acVoltages.append(v - mean);
}
```

#### 4. 数据补零到2的幂次

**原因**：FFT算法要求输入长度为2的幂次

```cpp
int SpectrumAnalyzer::nextPowerOf2(int n)
{
    int power = 1;
    while (power < n) {
        power *= 2;
    }
    return power;
}

// 补零
int N = nextPowerOf2(acVoltages.size());
QVector<std::complex<double>> complexData(N, 0.0);

for (int i = 0; i < acVoltages.size(); i++) {
    complexData[i] = std::complex<double>(acVoltages[i], 0.0);
}
```

#### 5. 幅度谱计算

**公式**：

$$
A_k = \frac{2}{N} \left| X_k \right|
$$

其中：
- $A_k$ = 频率k的幅度
- $N$ = FFT长度
- $X_k$ = FFT变换结果的复数值

```cpp
QVector<double> magnitude(N / 2);
for (int i = 0; i < N / 2; i++) {
    magnitude[i] = std::abs(complexData[i]) * 2.0 / N;
}
```

#### 6. 频率轴生成

**公式**：

$$
f_k = \frac{k \cdot f_s}{N}
$$

其中：
- $f_k$ = 频率索引k对应的实际频率
- $f_s$ = 采样率
- $N$ = FFT长度

```cpp
QVector<double> frequencies(N / 2);
for (int i = 0; i < N / 2; i++) {
    frequencies[i] = i * actualSampleRate / N;
}
```

#### 7. 主频率检测

```cpp
// 寻找最大峰值（跳过DC分量，从索引1开始）
int dominantIndex = 1;
double maxAmplitude = magnitude[1];

for (int i = 2; i < magnitude.size(); i++) {
    if (magnitude[i] > maxAmplitude) {
        maxAmplitude = magnitude[i];
        dominantIndex = i;
    }
}

result.dominantFrequency = frequencies[dominantIndex];
result.dominantAmplitude = maxAmplitude;
```

#### 8. 次频率检测

```cpp
// 寻找第二大峰值（排除主频附近的点，避免谐波干扰）
int secondIndex = 1;
double secondMax = 0.0;

for (int i = 1; i < magnitude.size(); i++) {
    // 排除主频附近±10%的频率范围
    if (std::abs(i - dominantIndex) > dominantIndex * 0.1) {
        if (magnitude[i] > secondMax) {
            secondMax = magnitude[i];
            secondIndex = i;
        }
    }
}

result.secondFrequency = frequencies[secondIndex];
result.secondAmplitude = secondMax;
```

## 频谱分析结果结构

### SpectrumAnalysisResult

```cpp
struct SpectrumAnalysisResult {
    double dominantFrequency;    // 主频率（Hz）
    double dominantAmplitude;    // 主频率对应的幅度（V）
    double secondFrequency;      // 次频率（Hz）
    double secondAmplitude;      // 次频率对应的幅度（V）

};
```

| FFT长度 | 频谱点数 | 数据量 |

| 2048 | 1024 | 8KB |
| 4096 | 2048 | 16KB |
| 8192 | 4096 | 32KB |

## 性能优化措施

### 1. 独立线程运行

```cpp
// 在独立线程中创建频谱分析器
QThread *spectrumThread = new QThread();
SpectrumAnalyzer *spectrumAnalyzer = new SpectrumAnalyzer();
spectrumAnalyzer->moveToThread(spectrumThread);
spectrumThread->start();
```

**优势**：FFT计算不阻塞UI线程

### 2. 延迟更新频谱图

```cpp
// 延迟150ms后更新，避免频繁重绘
QTimer::singleShot(150, this, [this, result]() {
    updateSpectrumPlot(result);
});
```

### 3. 分离数据标签更新

```cpp
// 频谱图更新：150ms
// 数据标签更新：500ms（定时器）
spectrumLabelUpdateTimer->setInterval(500);
```

**优势**：减少标签跳动，提高可读性

### 4. 模式切换资源管理

```cpp
// 切换到频谱模式时
if (isSpectrumMode) {
    // 断开数据处理器，减少CPU占用
    disconnect(udpReceiver, dataReceived, dataProcessor, ...);
    
    // 重新连接频谱分析器
    connect(udpReceiver, dataReceived, spectrumAnalyzer, ...);
    
    // 启动频谱更新定时器
    spectrumLabelUpdateTimer->start(500);
}
```

## FFT算法性能分析

### 时间复杂度对比

| 算法 | 时间复杂度 | 1024点耗时 | 8192点耗时 |
|------|-----------|-----------|-----------|
| DFT（直接计算） | O(N²) | ~1ms | ~60ms |
| FFT（Cooley-Tukey） | O(N log N) | ~0.1ms | ~1ms |

**性能提升**：10倍以上

### 内存占用

| FFT长度 | 内存占用 | 说明 |
|---------|---------|------|
| 1024 | ~16KB | 复数数组 + 结果数组 |
| 2048 | ~32KB | |
| 4096 | ~64KB | |
| 8192 | ~128KB | |

## 频谱分析应用场景

### 1. 信号频率识别

**示例**：检测1kHz正弦波

```
输入信号：1kHz, 2V幅度正弦波
采样率：50MHz
采样点数：1000

FFT结果：
- 主频率：1000.5 Hz
- 主幅度：1.98 V
- 次频率：3001.2 Hz（三次谐波）
- 次幅度：0.05 V
```

### 2. 谐波分析

**示例**：检测方波的谐波成分

```
输入信号：1kHz方波
FFT结果：
- 基波：1000 Hz, 1.27 V
- 三次谐波：3000 Hz, 0.42 V
- 五次谐波：5000 Hz, 0.25 V
- 七次谐波：7000 Hz, 0.18 V
```

### 3. 噪声分析

**示例**：检测信号中的干扰频率

```
输入信号：1kHz正弦波 + 50Hz工频干扰
FFT结果：
- 主频率：1000 Hz（有效信号）
- 次频率：50 Hz（工频干扰）
```
