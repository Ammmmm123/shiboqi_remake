## 📊 关键数据流图

### 示波器模式数据流

```text
FPGA (ADC采样，50MHz)
    │
    │ UDP数据包 (512个10-bit ADC值/包)
    ▼
UdpReceiver
    │
    ├─► ADC → 电压转换 (0-1023 → 0-5V)
    └─► 时间戳计算 (基于采样率)
            │
            ▼
    DataProcessor [独立线程]
            │
            ├─► 波形分析 (频率、幅度、峰峰值)
            │       └─► analysisReady → UI显示
            │
            └─► 智能降采样 (→ 3000点)
                    └─► downsampledDataReady → UI绘图 (50ms/帧)
```

### 频谱分析模式数据流

```text
FPGA (ADC采样)
    │
    │ UDP数据包
    ▼
UdpReceiver
    │
    │ 电压 + 时间戳
    ▼
SpectrumAnalyzer [独立线程]
    │
    ├─► FFT变换 (Cooley-Tukey算法)
    ├─► 幅度谱计算
    └─► 主/次频率检测
            │
            └─► spectrumReady → UI绘制频谱图
```

### 命令发送数据流

```text
UI用户操作
    │
    ├─► 重启采集 / 循环采集
    ├─► 通道选择 / 分频系数
    ├─► DDS波形 / 频率 / 幅度
    └─► 手绘波形数据
            │
            ▼
        UdpSender
            │
            │ 8字节命令包
            ▼
        FPGA命令解析模块
```

## 🔌 通信协议规范

### UDP接收数据包（FPGA → PC）

```text
数据包大小: 1024字节 (512个10-bit ADC值)
字节格式: [ADC0_H, ADC0_L, ADC1_H, ADC1_L, ...]
ADC值范围: 0-1023 (10-bit)
电压范围: 0-5V
```

### UDP发送命令包（PC → FPGA）

```text
数据包大小: 固定8字节
格式: [0xAA, 0x55, ADDR, P0, P1, P2, P3, 0xFF]
识别码: 0xAA, 0x55
结束标志: 0xFF
参数: 小端序
```

### UART接收数据（下位机 → PC）

```text
数据格式: ASCII文本，换行符结尾
模式: "占空比,高电平时间,低电平时间,频率\n"
示例: "50,1000,1000,500.0\n"
```
