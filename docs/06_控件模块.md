# 控件模块设计说明

## 模块概述

**文件位置**：

- `src/widgets/siprefixticker.cpp/h` - SI前缀刻度类
- `src/widgets/waveform_sender_thread.cpp/h` - 波形发送线程

**主要功能**：

- 自动单位转换（us/ms/s，mV/V等）
- 手绘波形UDP发送
- 进度反馈与错误处理

## SI前缀刻度类 (SIPrefixTicker)

### 类设计

**继承**：`QCPAxisTicker`

**作用**：根据坐标轴范围自动调整单位前缀（如μ、m、k、M等）

#### 核心成员变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `baseUnit` | `QString` | 基础单位（如"V"、"s"、"Hz"） |
| `currentPrefix` | `QString` | 当前使用的SI前缀（如"m"、"k"） |
| `currentScale` | `double` | 当前缩放因子（如0.001、1000） |

### SI前缀定义

| 前缀 | 符号 | 缩放因子 | 适用范围 | 示例 |
|------|------|---------|---------|------|
| 纳(nano) | n | 1e-9 | [1e-9, 1e-6) | 100ns |
| 微(micro) | μ | 1e-6 | [1e-6, 1e-3) | 500μs |
| 毫(milli) | m | 1e-3 | [1e-3, 1) | 50ms |
| 无 | (空) | 1 | [1, 1e3) | 5s |
| 千(kilo) | k | 1e3 | [1e3, 1e6) | 10kHz |
| 兆(mega) | M | 1e6 | [1e6, 1e9) | 50MHz |
| 吉(giga) | G | 1e9 | [1e9, ∞) | 1GHz |

### 自动单位切换流程

```text
坐标轴范围改变
        │
        ▼
SIPrefixTicker::getTickLabel(tick, ...)
        │
        ├─► 计算坐标轴范围的最大值
        │   └─► maxValue = max(abs(range.lower), abs(range.upper))
        │
        ├─► 根据最大值确定最佳前缀
        │   ├─► if (maxValue < 1e-6) → prefix = "n", scale = 1e9
        │   ├─► else if (maxValue < 1e-3) → prefix = "μ", scale = 1e6
        │   ├─► else if (maxValue < 1) → prefix = "m", scale = 1e3
        │   ├─► else if (maxValue < 1e3) → prefix = "", scale = 1
        │   ├─► else if (maxValue < 1e6) → prefix = "k", scale = 1e-3
        │   ├─► else if (maxValue < 1e9) → prefix = "M", scale = 1e-6
        │   └─► else → prefix = "G", scale = 1e-9
        │
        ├─► 缩放刻度值
        │   └─► scaledValue = tick * scale
        │
        ├─► 格式化标签文本
        │   └─► label = QString::number(scaledValue, 'f', precision)
        │
        └─► 更新坐标轴标题
            └─► axis->setLabel("Time (" + prefix + baseUnit + ")")
```

### 实现代码

```cpp
QString SIPrefixTicker::getTickLabel(double tick, const QLocale &locale, 
                                     QChar formatChar, int precision)
{
    Q_UNUSED(locale);
    Q_UNUSED(formatChar);
    
    // 获取坐标轴范围
    QCPRange range = mParentAxis->range();
    double maxValue = qMax(qAbs(range.lower), qAbs(range.upper));
    
    // 确定最佳前缀和缩放因子
    QString prefix;
    double scale;
    
    if (maxValue < 1e-6) {
        prefix = "n";
        scale = 1e9;
    } else if (maxValue < 1e-3) {
        prefix = "μ";
        scale = 1e6;
    } else if (maxValue < 1) {
        prefix = "m";
        scale = 1e3;
    } else if (maxValue < 1e3) {
        prefix = "";
        scale = 1;
    } else if (maxValue < 1e6) {
        prefix = "k";
        scale = 1e-3;
    } else if (maxValue < 1e9) {
        prefix = "M";
        scale = 1e-6;
    } else {
        prefix = "G";
        scale = 1e-9;
    }
    
    // 更新当前前缀和缩放因子
    currentPrefix = prefix;
    currentScale = scale;
    
    // 缩放刻度值
    double scaledValue = tick * scale;
    
    // 格式化标签
    if (precision < 0) precision = 2;
    return QString::number(scaledValue, 'f', precision);
}

QString SIPrefixTicker::unitLabel() const
{
    if (currentPrefix.isEmpty()) {
        return baseUnit;
    }
    return currentPrefix + baseUnit;
}
```

## 波形发送线程 (WaveformSenderThread)

### 类设计

**继承**：`QThread`

**作用**：在独立线程中发送手绘波形数据，避免阻塞主线程

#### 核心成员变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `m_waveformData` | `QVector<quint16>` | 1024个采样点的波形数据 (0-1023) |
| `m_targetAddress` | `QHostAddress` | 目标IP地址 |
| `m_targetPort` | `quint16` | 目标端口 |
| `m_delayMs` | `int` | 每个数据包发送间隔（毫秒） |

### 波形发送流程

```text
用户绘制波形 → 插值为1024点 → 点击"保存并发送"
        │
        ▼
创建 WaveformSenderThread
        │
        ├─► waveformData = handDrawnWaveform (1024点)
        ├─► targetAddress = "192.168.0.2"
        ├─► targetPort = 5000
        └─► delayMs = 1 (每个包间隔1ms)
                │
                ▼
thread->start()
        │
        ▼
run() 在独立线程中执行
        │
        ├─► 创建UDP套接字
        │   └─► QUdpSocket socket
        │
        ├─► 切换下位机到手绘波形模式
        │   └─► sendWaveformCommand(type=4)
        │
        ├─► 循环发送1024个数据包
        │   └─► for (i = 0; i < 1024; i++)
        │       {
        │           ├─► 构建8字节命令包
        │           │   ├─► Byte 0-1: 0xAA, 0x55 (识别码)
        │           │   ├─► Byte 2: 0x0C (手绘波形命令)
        │           │   ├─► Byte 3-4: voltage (10-bit值，小端序)
        │           │   ├─► Byte 5-6: 0x00, 0x00
        │           │   └─► Byte 7: 0xFF (结束标志)
        │           │
        │           ├─► socket->writeDatagram(packet, ...)
        │           │
        │           ├─► 发射进度信号
        │           │   └─► emit progressUpdated(i+1, 1024)
        │           │
        │           └─► 延迟1ms
        │               └─► QThread::msleep(delayMs)
        │       }
        │
        ├─► 发射完成信号
        │   └─► emit sendingCompleted(successCount, 1024)
        │
        └─► 如果发生错误
            └─► emit sendingFailed(errorMessage)
```

### 关键函数实现

#### 1. 构建波形数据包

```cpp
QByteArray WaveformSenderThread::buildWaveformPacket(quint16 voltageValue)
{
    QByteArray packet(8, 0);
    
    // 识别码
    packet[0] = static_cast<char>(0xAA);
    packet[1] = static_cast<char>(0x55);
    
    // 地址位：手绘波形命令
    packet[2] = static_cast<char>(0x0C);
    
    // 参数位：10-bit电压值（小端序，占2字节）
    packet[3] = static_cast<char>(voltageValue & 0xFF);        // 低字节
    packet[4] = static_cast<char>((voltageValue >> 8) & 0xFF); // 高字节
    
    // 保留字节
    packet[5] = 0x00;
    packet[6] = 0x00;
    
    // 结束标志
    packet[7] = static_cast<char>(0xFF);
    
    return packet;
}
```

#### 2. 线程运行函数

```cpp
void WaveformSenderThread::run()
{
    if (m_waveformData.size() != 1024) {
        emit sendingFailed("波形数据点数不正确（应为1024点）");
        return;
    }
    
    // 创建UDP套接字
    QUdpSocket socket;
    
    int successCount = 0;
    
    // 发送1024个数据包
    for (int i = 0; i < 1024; i++) {
        // 构建数据包
        QByteArray packet = buildWaveformPacket(m_waveformData[i]);
        
        // 发送数据包
        qint64 sent = socket.writeDatagram(packet, m_targetAddress, m_targetPort);
        
        if (sent == packet.size()) {
            successCount++;
        }
        
        // 发射进度信号
        emit progressUpdated(i + 1, 1024);
        
        // 延迟
        if (m_delayMs > 0) {
            QThread::msleep(m_delayMs);
        }
    }
    
    // 发射完成信号
    emit sendingCompleted(successCount, 1024);
}
```

### 信号定义

| 信号名 | 参数 | 说明 | 发射频率 |
|--------|------|------|---------|
| `progressUpdated` | `int current, int total` | 发送进度 | 每个数据包 |
| `sendingCompleted` | `int successCount, int totalCount` | 发送完成 | 1次 |
| `sendingFailed` | `QString errorMessage` | 发送失败 | 1次（出错时） |

### UI进度显示


## 手绘波形完整流程

### 1. 手绘数据采集

```text

        │
        ▼
鼠标按下 (MouseButtonPress)
        │
        ├─► isDrawing = true
        └─► handDrawnPoints.clear()
                │
                ▼
鼠标移动 (MouseMove)
        │
        ├─► 获取屏幕坐标
        ├─► 转换为绘图坐标 (x∈[0,1], y∈[0,1023])
        ├─► handDrawnPoints.append(point)
        └─► 实时显示轨迹
                │
                ▼
鼠标释放 (MouseButtonRelease)
        │
        └─► isDrawing = false
```

### 2. 插值为1024点

```cpp
void shiboqi_remake::interpolateHandDrawnWaveform()
{
    handDrawnWaveform.clear();
    
    if (handDrawnPoints.size() < 2) return;
    
    // 按X坐标排序
    std::sort(handDrawnPoints.begin(), handDrawnPoints.end(), 
              [](const QPointF &a, const QPointF &b) {
                  return a.x() < b.x();
              });
    
    const int NUM_SAMPLES = 1024;
    
    // 线性插值生成1024个点
    for (int i = 0; i < NUM_SAMPLES; i++) {
        double targetX = i / (NUM_SAMPLES - 1.0); // 0.0 ~ 1.0
        
        // 找到targetX左右两个点
        int leftIdx = 0;
        for (int j = 0; j < handDrawnPoints.size() - 1; j++) {
            if (handDrawnPoints[j].x() <= targetX && 
                handDrawnPoints[j+1].x() >= targetX) {
                leftIdx = j;
                break;
            }
        }
        
        // 线性插值
        double x0 = handDrawnPoints[leftIdx].x();
        double x1 = handDrawnPoints[leftIdx + 1].x();
        double y0 = handDrawnPoints[leftIdx].y();
        double y1 = handDrawnPoints[leftIdx + 1].y();
        
        double t = (targetX - x0) / (x1 - x0);
        double y = y0 + t * (y1 - y0);
        
        // 限制范围并转换为整数
        quint16 value = static_cast<quint16>(qBound(0.0, y, 1023.0));
        handDrawnWaveform.append(value);
    }
}
```

### 3. Y轴翻转

**原因**：绘图坐标系和实际显示坐标系Y轴方向相反

```cpp
void shiboqi_remake::flipYAxisData()
{
    for (int i = 0; i < handDrawnWaveform.size(); i++) {
        handDrawnWaveform[i] = 1023 - handDrawnWaveform[i];
    }
}
```

### 4. 发送波形

```cpp
void shiboqi_remake::sendHandDrawnWaveform()
{
    // 创建发送线程
    waveformSenderThread = new WaveformSenderThread(
        handDrawnWaveform,
        QHostAddress("192.168.0.2"),
        5000,
        1, // 1ms延迟
        this
    );
    
    // 连接信号
    connect(waveformSenderThread, &WaveformSenderThread::progressUpdated,
            this, &shiboqi_remake::onWaveformSendProgress);
    connect(waveformSenderThread, &WaveformSenderThread::sendingCompleted,
            this, &shiboqi_remake::onWaveformSendCompleted);
    connect(waveformSenderThread, &WaveformSenderThread::sendingFailed,
            this, &shiboqi_remake::onWaveformSendFailed);
    
    // 线程完成后自动清理
    connect(waveformSenderThread, &WaveformSenderThread::finished,
            waveformSenderThread, &QObject::deleteLater);
    
    // 启动线程
    waveformSenderThread->start();
}
```

## 性能与优化

### 1. 线程安全

```cpp
// 使用Qt::QueuedConnection确保跨线程信号安全
connect(thread, &Thread::signal, this, &Class::slot, Qt::QueuedConnection);
```

### 2. 内存管理

```cpp
// 线程完成后自动删除，避免内存泄漏
connect(thread, &QThread::finished, thread, &QObject::deleteLater);
```

### 3. 发送速率控制

```cpp
// 每个数据包间隔1ms，总耗时约1秒（1024点）
```
